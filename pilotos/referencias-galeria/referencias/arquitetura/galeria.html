Peças animadas para montar (licença aberta)

  • Aceternity UI (grátis): npx shadcn@latest add @aceternity/<peça> · licença própria: uso livre em site de cliente; modelos e blocos Pro são pagos
  • Magic UI: npx shadcn@latest add @magicui/<peça> · MIT
  • React Bits: npx shadcn@latest add @react-bits/<peça> · MIT + Commons Clause (não revender a peça)
  • Motion Primitives: npx shadcn@latest add @motion-primitives/<peça> · MIT
  • Animata: npx shadcn@latest add https://animata.design/r/<grupo>/<peça>.json · MIT
  • Uiverse: copiar da página (sem registro) · MIT
  • 21st.dev: pela página de cada peça · varia por autor: conferir na página
