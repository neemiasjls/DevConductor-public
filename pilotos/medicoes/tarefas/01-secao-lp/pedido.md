Crie uma seção de serviços para o Ateliê Horizonte, um negócio fictício de manutenção
de bicicletas. Use somente HTML, CSS e JavaScript locais, sem bibliotecas, downloads ou
instalações. Trabalhe apenas nesta pasta. Leia pronto-quando.md antes de começar.

A seção deve ter o título “Serviços”, o aviso “Negócio fictício — demonstração” e três
serviços: “Revisão essencial” (R$ 90), “Ajuste de freios” (R$ 45) e “Troca de pneus”
(R$ 60). Cada serviço deve ter uma frase curta explicando o que inclui. Um link
“Ver contato” deve levar ao bloco #contato, com o texto “Contato demonstrativo”.

Organize os serviços em uma coluna no celular e três no computador. Faça uma animação
curta de entrada usando CSS, sem repetição, e desative-a quando a pessoa preferir
movimento reduzido. O conteúdo precisa estar visível mesmo sem JavaScript. Use HTML
semântico, contraste legível e foco de teclado visível. Siga o contrato de seletores
do critério para permitir a conferência automática.

Não altere pedido.md, pronto-quando.md, package.json, servir.mjs nem os testes
fornecidos. Pode criar testes adicionais. Rode npm test e informe o resultado e os
arquivos que mudou. Não faça commit nem publique.
