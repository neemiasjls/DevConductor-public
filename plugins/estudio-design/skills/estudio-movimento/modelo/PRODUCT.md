# Estúdio de movimento

## Platform
Web local, computador e celular.

## Público e tarefa
Pessoas que criam sites precisam ver opções de movimento funcionando antes de escolher uma cena.
Este modelo entrega estudos demonstrativos isolados, gravações e uma vitrine de escolha.

## Stack
React + GSAP, conforme o roteiro D1. Vite serve os exemplos locais; não há backend nem dados pessoais.

## Restrições
Sem publicação automática. Nenhum favorito é aprovado automaticamente. Fotos reais com licença/crédito,
conteúdo identificado como demonstrativo, título principal independente da animação, pausa,
movimento reduzido e versão vertical no celular. Não substitui o método de construção do projeto.
